The method behind the numbers

Four techniques, each standard in manufacturing and healthcare capacity planning. Each one ends with a concrete deliverable.

Process mining

A map of your real process, with every detour. We read the event logs your systems already keep to see how work actually flows.

Discrete-event simulation

The queue points in your pipeline, costed in £/month, from a working model calibrated against your own data.

Queueing analysis

The staffing arithmetic for each stage, using the same maths call centres and A&E departments plan with.

Scenario testing

An expected value for each candidate fix, with confidence intervals, measured in the model before you commit.

Built on what really happens

Every suggestion we make comes from a working model of how your business actually runs, built from your own records rather than from how anyone describes the work. If a change does not pay in the model, we will not recommend it.

Client confidentiality

We strip names before anything is modelled and work from workflow timestamps alone. The model finds bottlenecks in how work moves, and it never scores individuals.
